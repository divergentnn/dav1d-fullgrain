WebCodecs grain check

Decodes each vector's grain-free MP4 with the browser's own AV1 decoder (WebCodecs), checks the pictures against dav1d (grain off), applies the grain on the GPU and checks again (full-frame grain). Also decodes the original MP4 to see which grain, if any, the browser applies itself. Query: ?vec=URL&hw=no-preference|prefer-hardware|prefer-software&only=name
